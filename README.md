# 📈 Stock Trading System

A full-stack paper-trading stock market simulator. Watch live (simulated)
prices, build a portfolio with virtual cash, track gains/losses, and keep a
watchlist — all backed by a REST API.

> **Note:** Prices are generated by a built-in random-walk simulator, so the app
> is fully self-contained and needs no external market-data provider or API key.

## Stack

- **Backend** — Node.js + Express REST API, JSON-file persistence, a background
  price simulator that ticks every few seconds.
- **Frontend** — React (Vite) single-page app that polls the API and renders a
  trading dashboard.

## Project layout

```
server/   Express API
  src/
    index.js                 app entry + server
    store.js                 JSON-file data store + seed data
    services/priceSimulator.js
    routes/                  stocks, portfolio, watchlist
client/   React + Vite frontend
  src/
    App.jsx
    api/client.js            fetch wrapper
    components/              Market, Holdings, Watchlist, Transactions, TradeModal
```

## Running locally

You need **Node.js 18+**. Open two terminals.

### 1. Backend

```bash
cd server
npm install
npm start            # http://localhost:4000
```

### 2. Frontend

```bash
cd client
npm install
npm run dev          # http://localhost:5173
```

The Vite dev server proxies `/api` to the backend on port 4000, so just open
**http://localhost:5173**.

## Features

- **Live market** — 10 seeded stocks with prices that drift every 3 seconds.
- **Buy / sell** — trade against $100,000 of starting virtual cash with
  validation (funds, share counts).
- **Portfolio** — holdings valued at live prices, average cost, and unrealized
  gain/loss per position plus overall totals.
- **Watchlist** — star any stock to track it.
- **Trade history** — every buy/sell recorded with price, quantity, and timestamp.
- **Reset** — restore starting cash and clear history at any time.

## API reference

| Method | Endpoint                          | Description                       |
| ------ | --------------------------------- | --------------------------------- |
| GET    | `/api/health`                     | Health check                      |
| GET    | `/api/stocks`                     | All stocks with live quotes       |
| GET    | `/api/stocks/:symbol`             | Single stock quote                |
| GET    | `/api/portfolio`                  | Portfolio with live valuation     |
| POST   | `/api/portfolio/buy`              | Buy shares `{ symbol, shares }`   |
| POST   | `/api/portfolio/sell`             | Sell shares `{ symbol, shares }`  |
| GET    | `/api/portfolio/transactions`     | Trade history                     |
| POST   | `/api/portfolio/reset`            | Reset portfolio + history         |
| GET    | `/api/watchlist`                  | Watched stocks with quotes        |
| POST   | `/api/watchlist`                  | Add symbol `{ symbol }`           |
| DELETE | `/api/watchlist/:symbol`          | Remove symbol                     |

## Configuration

| Env var   | Default | Description                          |
| --------- | ------- | ------------------------------------ |
| `PORT`    | `4000`  | Backend HTTP port                    |
| `TICK_MS` | `3000`  | Price simulator tick interval (ms)   |
